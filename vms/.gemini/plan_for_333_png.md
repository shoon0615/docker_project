# 봉사 신청 페이지 상세 구현 계획 (`.gemini/333.png`)

## 0. 목표
`.gemini/333.png` 이미지에 명시된 모든 기능을 포함하는 동적이고 반응형인 봉사 신청 페이지를 구현합니다. 이 계획은 구현 단계를 구체화하고 추가 사용자 경험(UX) 기능을 포함합니다.

---

## 단계 1: 기본 구조 및 정적 레이아웃 구성

### 1.1. 페이지 및 라우팅 설정
*   **파일 생성**: `app/(default-layout)/volunteer` 경로에 `page.tsx` 파일을 생성하여 새로운 봉사 신청 페이지의 기반을 마련합니다.
*   **기본 레이아웃 활용**: 기존 `app/(default-layout)/layout.tsx`를 활용하여 일관된 상단 네비게이션과 기본 구조를 유지합니다.

### 1.2. 헤더 영역 구성
*   **로고 및 메인 네비게이션**:
    *   좌측 상단에 **사회복지 자원봉사 인증관리 로고**를 배치하고, 클릭 시 메인 페이지(`/`)로 이동하도록 `Link` 컴포넌트로 감쌉니다.
    *   "봉사안내", "봉사인증", "전문봉사", "봉사신청" 등 주요 메뉴 항목을 `NavigationMenu`를 사용하여 구현합니다.
*   **사용자 인증 링크 (Placeholder)**:
    *   우측 상단에 "로그인", "회원가입" 링크를 위한 컴포넌트(`AuthLinks.tsx`)를 생성하고 배치합니다.
    *   **참고**: 실제 인증 기능은 후반 단계(단계 4)에서 구현하며, 현재는 UI만 구성합니다.

### 1.3. 서브 헤더 및 타이틀 영역
*   **배너 이미지**: 메인 네비게이션 아래에 위치한 손을 잡고 있는 일러스트 배너 이미지를 추가합니다.
*   **Breadcrumb 네비게이션**:
    *   `components/ui/breadcrumb` 컴포넌트를 사용하여 "홈 > 봉사신청 > 봉사자모집 및 신청" 형태의 경로를 표시합니다.
*   **페이지 제목**: "봉사자모집 및 신청" 이라는 명확한 `<h1>` 제목을 추가합니다.

### 1.4. 푸터 영역 구성
*   하단 푸터에 "이용약관", "개인정보처리방침" 등의 링크와 관련 기관 로고(VMS, 보건복지부 등) 및 저작권 정보를 포함하여 `Footer.tsx` 컴포넌트로 구현합니다.

---

## 단계 2: 핵심 기능 및 컴포넌트 개발

### 2.1. 필터 및 검색 섹션
*   **활동 분야/주기 탭**:
    *   `components/ui/tabs.tsx` 컴포넌트를 기반으로, 각 탭에 **아이콘**과 텍스트("시설봉사", "재가봉사" 등)를 함께 표시하는 `IconTab.tsx` 컴포넌트를 구현합니다.
*   **상세 검색 폼**:
    *   `Card` 컴포넌트 내부에 검색 폼을 구성하여 시각적으로 그룹화합니다.
    *   **필드 구성**: "활동지역", "활동유형", "모집현황" 등 `Select` 컴포넌트를, "봉사기간", "모집기간"은 `Calendar` 또는 `DatePicker` 컴포넌트를 사용합니다. "청소년도 참여 가능해요" `Checkbox`를 추가합니다.
    *   **상세 검색 토글**: "상세검색" 버튼 클릭 시 추가 필터(`활동주기`, `검색조건`)가 나타나고 사라지는 동적 기능을 구현합니다.
    *   폼 하단에 "검색" `Button`을配置합니다.

### 2.2. 봉사 기회 목록 섹션
*   **총 건수 표시**:
    *   "총 N 건" 형태로 API로부터 받은 데이터의 총 개수를 목록 상단에 표시하는 UI를 구현합니다.
*   **봉사 기회 카드 컴포넌트 (`VolunteerOpportunityCard.tsx`)**:
    *   `Card` 컴포넌트를 기반으로 각 봉사 목록 아이템을 표시합니다.
    *   **내용**: 지역/유형 `Badge` (예: "서울", "대면"), 봉사 제목, 기관명, 봉사 기간(`Icon`과 함께), 신청 현황(예: "0 / 5명"), 모집 상태 `Badge`("모집중")를 모두 포함합니다.
*   **카드 그리드 레이아웃**:
    *   `VolunteerOpportunityCard` 컴포넌트들을 반응형 그리드 레이아웃으로 표시합니다.

### 2.3. 페이지네이션
*   `components/ui/pagination.tsx`을 사용하여 목록 하단에 페이지 이동 기능을 구현하고, 현재 페이지와 총 페이지 수를 명확히 표시합니다.

## 단계 3: 상호작용 및 사용자 경험(UX) 향상

### 3.1. 데이터 연동 (Mock Data)
*   실제 API가 준비되기 전까지, `VolunteerOpportunityCard`에 필요한 모든 필드를 포함하는 목업 데이터 배열을 생성하여 UI 개발 및 테스트에 사용합니다.

### 3.2. 로딩 상태 표시
*   데이터를 불러오는 동안 사용자에게 대기 상태임을 알리기 위해 `Spinner` 또는 스켈레톤 UI를 표시합니다.
    *   **스켈레톤 UI**: `VolunteerOpportunityCard`와 유사한 형태의 스켈레톤 컴포넌트를 여러 개 표시하여 로딩 중임을 시각적으로 나타냅니다.

### 3.3. "맨 위로 이동" 버튼
*   `SidebarRail`과 유사하게, 사용자가 페이지를 아래로 스크롤하면 화면 우측 하단에 나타나는 고정 위치 버튼을 구현합니다.
*   이 버튼을 클릭하면 페이지의 맨 위로 부드럽게 스크롤되는 기능을 추가합니다.
